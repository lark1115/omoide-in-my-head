# 測るための記録と道具

装置の記録だけでは、装置が呼ばれなかった機会は数えられない。そこで、装置が持つ記録と、比べるための道具を分ける。

装置が持つ記録:

- (a) 呼び出しごとに、時刻、種類（登録／問い合わせ／書き出し）、かかった時間、返した記録の識別子、返した量を記録する。呼び出した側は、機会の識別子を添えられる。問い合わせの文そのものを残すかどうかは、設定で選べる（既定は残さない）。
- (b) 呼び出した側は、「この結果を使った」「この動作をした」「利用者に指摘された」を、機会の識別子と、記録の識別子に結びつけて知らせられる。
- (c) 装置は、決まりごとに、できたあとの指摘の回数と、その決まりの動作の機会の回数を、並べて出せる。同じ機会の識別子は、1 回に数える。機会が 0 回の決まりは、「測れていない」と出す。
- (d) 同じ決まりへの指摘がくり返された時、装置は、その決まりを「検査や仕組みに変える候補」として、一覧に出す。

比べるための道具:

- (e) 道具は、決めた場面の集まりを流す。場面ごとに、正しい記録、返ってはいけない記録を、ファイルで渡す。道具は、場面ごとに、正しい記録が全部返ったか、返ってはいけない記録や前の版が返ったか、返した量を出す。
- (f) 道具は、同じ場面、同じ初めの保存、同じ設定、判定の層の決まった答えで、2 つの版の結果を比べる。違いを、前もって認めた違いと、説明の付かない違いに分けて出す。
- (g) 装置を組み込んだ LLM での比べ（装置あり／装置なし／常に読み込まれる節だけ）は、道具が試行ごとに機会の識別子を振る。試行ごとに、動作の前に結果が LLM に届いたか、LLM が使ったか、動作、指摘を記録する。装置が呼ばれなかった試行も、分母に残す。前後の順が見えなかった試行は「不明」とし、成功に数えない。LLM の入力に足した量は、実際に渡した節と結果で数える。
- (h) 公開する試験のデータと結果は、作り物の場面で作る。実際の利用者の問い合わせの文を、公開する物に入れない。

出どころ: BR-15、BR-16、BR-20。
