# 判定の層

- (a) 核と保存は、通信の部品に依らない。判定の層は、口ごしに、別の部品として付ける。
- (b) 判定の層が設定されていなくても、登録と問い合わせは動く。この時の探し方は、区切った語の当たりである。
- (c) 問い合わせの結果は、判定の層の状態と、見つかった記録の数を、別々に示す。

| 判定の層の状態 | 意味 |
|---|---|
| 設定が無い | 判定の層を使っていない |
| 使った | 判定の層の答えを、順位に使った |
| 失敗した | 時間切れ、通信の失敗、形の合わない返事 |

- (d) 「失敗した」の時も、判定の層を使わない探し方の結果を返す。結果を捨てない。「当てはまる物が無い」は、探した結果が 0 件の時にだけ返す。
- (e) 判定の層の答えを採るかどうかは、核が決める。決め方の値は、設定で変えられる。
- (f) 判定の層を別の物に替えても、保存した記録は変わらない。
- (g) 外の判定の層へ文を送るのは、利用者がその判定の層を設定した時だけである。何を送るかは、判定の層の部品ごとに、文書に書く。

出どころ: BR-8、BR-14。

- (h) 種類・対象・明示された動作で候補を絞り、入力上限内の束に分ける。全体の期限を共有し、完了した束の結果と未判定件数を返す（BR-21、BR-22）。
