# 組み込み

- (a) README と AGENTS.md だけを読んだ LLM のエージェントが、空の保存先から、次の一巡を終えられる: 入れる、利用者の発言と決まりを 1 つ登録する、プロセスも会話も新しくして、前の文脈を渡さずに、場面の文で問い合わせ、その決まり（動作、またはスキルの参照先）と元の発言を受け取る。
- (b) (a) の一巡は、Muse の VM と、Muse でない Linux の両方で確かめる。
- (c) 手引きは、既にある指示ファイルの決まりを、装置へ登録する手順を持つ。どの決まりを移すかは、組み込む側が選ぶ。装置は、指示ファイルの全体を書き換えない（書くのは REQ-HOT-1 の 1 節だけである）。
- (d) 手元の SQLite を使い、判定の層を使わない基本の形は、コンパイラ、GPU、ネットワークなしで動く。
- (e) 文書の例と、試験のデータは、作り物の場面で書く。特定の利用者の名前、パス、設定を入れない。
- (f) 命令の結果は、機械が読める形で受け取れる。失敗は、終了コードと、理由の文で返す。使える結果がある時は、一部の失敗（判定の層の失敗など）で結果を捨てない。

出どころ: BR-2、BR-3、BR-5b。
