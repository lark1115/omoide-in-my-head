# 記録の種類と履歴

装置は、次の種類の記録を持つ。種類は、問い合わせの結果で区別して返る。

| 種類 | 中身 |
|---|---|
| 発言 | 利用者の言葉。受け取った文のまま、一字も変えない |
| 決まり | どの場面で、何をするか（または、どのスキルを読むか） |
| 決めたこと | 利用者が決めた事、提案、判断待ちの事 |
| 事実 | 知っている事、確かめた事、済んだ作業、渡された物の在りか、概念や物事の説明 |
| 経験 | 起きた出来事。いつ、何をして、どうなったか |
| スキル | 経験から上がった、すぐ出せる動作。本文がファイルにあれば、その参照先 |

満たすこと:

- (a) 発言は、書いたあと、変えられない。
- (b) 利用者の発言から作った決まり、決めたこと、要約の事実は、出どころの発言を必ず持つ。出どころの無い登録は、失敗にする。経験から作ったスキルと事実は、出どころの経験を必ず持つ。装置は、無い発言を出どころとして作らない。
- (c) 問い合わせの結果の記録から、出どころの本文の全体、時点、対象へ、識別子でたどれる。長い発言の後ろの方にある条件も、取り出せる。
- (d) 装置は、記録を自分からは消さない。記録を改める時は、新しい版を足し、前の版に「置き換え済み」の印と、置き換えた版の識別子を付ける。
- (e) ふだんの問い合わせには、今の版だけが返る。履歴を指定した問い合わせには、前の版も、置き換え済みの印と一緒に返る。
- (f) 存在しない識別子を引いた時は、「無い」を返す。空の成功を返さない。
- (g) 秘密の値を持つための場所を、用意しない。渡された物は、在りかと参照先で持つ。装置は、文の中の秘密を見つけない。秘密を含む文を渡さないことは、呼び出す側の役目として、手引きに書く。

出どころ: BR-4、BR-10、BR-11、BR-13。
