# 決まりの登録と照らし合わせ

- (a) 決まりは、使う場面、動作の名前（複数可）、当てはまる対象（案件や相手。無ければ「どれにも」）を持つ。
- (b) 決まりは、守る目的と、当てはめない範囲を持てる。登録の時に与えられなかった物は、空のまま持つ。装置は、これを補って作らない。
- (c) 登録の時、装置は、今の版の決まりの中から「近い決まり」を機械的に探す。本文・場面・別表現に共通する内容語や、場面に明示された対象の手掛かりを使う。保存先の現行規則で頻出する語を弱め、場面を特定しない定型文の一致を区別する。動作名・対象名の指定や助詞・語尾の一致だけでは近いとしない。根拠の強い順に最大9件と未表示件数を返す。判定の層は要らない。
- (d) 近い決まりが無ければ、その場で今の版になる。登録の呼び出しが成功したあとの、最初の問い合わせから返る。経験の回数を待たない。関門（REQ-PROMO-1）を通らない。
- (e) 近い決まりがある時、装置は、近い決まりと、その元の発言を返す。呼び出した側（LLM）は、関係を 1 つ選んで登録を終える。

| 関係 | 意味 | 装置の動き |
|---|---|---|
| 同じ | 同じ決まりの送り直し、または、言い方だけが違う | 二重に持たない。出どころを足す |
| 言い直し | 利用者が、前の決まりを改めた | 新しい方が今の版になる。前の版に「置き換え済み」の印が付く |
| 例外 | 前の決まりの一部にだけ当てはまる、別の決まり | 両方が今の版になる。新しい方に、当てはまる対象を付ける。前の決まりは退けない |
| 別の話 | 近く見えるが、関係が無い | 新しい方が今の版になる |
| 分からない | 食い違うが、どちらが有効か、利用者の言葉から決められない | 新しい方は「判断待ち」になる。今の版を上書きしない |

- (f) 登録の結果は、次のどれかを返す: 有効になった／同じ物があった／前の版を置き換えた／判断待ち／保存に失敗した。
- (g) 「判断待ち」の決まりは、利用者の判断が登録されるまで、そのままである。判断待ちを返す時は、いつも、新しい決まりと今の版の決まりの両方を、それぞれの元の発言の本文と一緒に返す（登録の結果でも、問い合わせの「未解決の食い違い」でも）。呼び出した側は、その両方を利用者に見せて確かめる。この手順を、手引きに書く。判断の登録で、どちらかが今の版になり、もう片方に「置き換え済み」か「退けた」の印が付く。
- (h) 関係を選ばずに登録を終えようとした時は、失敗にする。黙って今の版にしない。黙って判断待ちにもしない。

利用者が明示で言い直した時は、確かめを挟まずに置き換える（(e) の「言い直し」）。利用者に聞くのは、「分からない」の時だけである。

出どころ: BR-5、BR-5b、BR-16、BR-17。
