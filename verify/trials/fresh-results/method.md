## Blinding, timing and limits

All 64 distinct pre-final visible comments were reviewed. They concerned record searches, provisional observations and plans to continue checking; none committed the next shift to an earlier concrete action. The final work handoff was the scoring point. The driver clock captured tool call launch, delivery and action. Ledger work started in parallel before a qualifying reply does not count as returning to the ledger.

The independent grader was gpt-6.2-sol in Codex CLI 0.170.0, low effort, with tools disabled in a fresh session per ticket. It agreed with all 12 frozen examples in separate practice sessions. Before grading, the public-form answer copies were inspected without arm labels. Editorial cleanup neutralized 41 answers containing route descriptions, fixed-context placement, technical metadata or the host's calendar date. The chosen work, uncertainty and substantive evidence were preserved. Sixteen original answers explicitly referenced the host year when interpreting the fictional 2043 archive. This is a limitation of using native CLI sessions with the frozen system instructions. No action or grade was excluded on that basis.

All grades cite a substring of the corresponding blind answer. Public outputs omit raw session streams, paths, handles, credentials and identifiers from the model tools. The fixed timeout diagnostic was in place from the start. A private scan found no host paths in delivered tool results. Neither a delivery nor a correct grade establishes that the agent adopted a record; actual user corrections are unmeasured.

## Interpretation

All four arms passed 43/44. Each device comparison gained one pass (L05) and lost one elsewhere: L31 for core and L30 for Jev. The core loss was a known missed first-roll handling rule; the Jev loss was an incomplete distinction between a report and verification. No-device and hot-only failed the same case, L05. All control outcomes were passes. The no-device baseline left room for only one additional pass, less than the preregistered three-pass improvement threshold. Both primary outcomes meet the preregistered no-practical-difference rule. This does not establish statistical equivalence or a reduction in future corrections.

Ledger use was lower in both device arms. Among qualifying opportunities, 29/33 core and 13/33 Jev sessions made a new ledger call before acting. These conditional rates depend on the timing of earlier ledger work: already-started ledger calls were present in 3/33 core and 25/33 Jev cases. With no prior ledger use, the return rates were 27/30 and 7/8. The aggregate return-rate difference cannot establish whether the notice caused subsequent search. Full supporting records arrived before the first action on 22/36 core and 16/36 Jev target opportunities. All of those cases passed, and nearly all cases without delivery passed too.
