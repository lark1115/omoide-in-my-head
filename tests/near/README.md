# 日本語の登録チェック

関係のない30件を同じ汎用動作名・同じ対象で順に登録する。逆順でも試し、全435組がどちらの順でも競合確認なしで登録できることを確かめる。追加の10件は、番号で指定した規則の言い換え4件・例外3件・矛盾3件。動作名を変えても元の版が表示枠に入り、逆向きでも比較されることを確認する。要約値だけで関係を省いた確定は失敗しなければならない。

素材はすべて架空。TSVと分割方針をしきい値の選定前に固定した。このセットは日本語の合格条件であり、未見の正解率を推定するものではない。

```sh
python3 tests/near/validate.py
cargo build --release --locked -p omoide
python3 tests/near/validate.py --binary target/release/omoide
```
