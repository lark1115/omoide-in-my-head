# 似た規則の識別試験

架空の巡業人形劇団の**同じ72規則**に対する152照会。舞台幕、楽器、頭部、合図札、衣装、影板、舞台紐、客席の8分野に各9規則がある。一つの動作に複数の対象があり、一つの対象にも状態で結論の変わる規則がある。日英の規則を混在させた。判定器あり・なしで「正しい規則を初回に返せたか」と「もっともらしい別の規則まで返したか」を別々に測るためのデータである。

| 設問の例 | 正解の決め手 |
|---|---|
| Q001 / Q002 | 同じ雨幕でも濡れていれば吊り、乾いていれば巻く。 |
| Q011 | 雨幕の状態、運び方、共用の三つを満たす。三規則すべてが必要。 |
| Q129 | 語と対象はほぼ一致するが、縫い直し待ちなので該当なし。 |
| Q005 / Q016 | 入力は動作と対象だけ。帆布幕にはその指定だけで発動する規則があり、小雪幕にはない。 |

正解なしは40件、正解2件は16件、3件は8件。照会ごとに異なる数の規則を選べるようにし、常に1件返す方式も、動作名が同じ規則を全部返す方式も誤りを検出できるようにした。どの規則も、少なくとも一度は必須、別の照会では禁止になる。

## ファイルと入力の境界

- `rules.jsonl` の1行が1規則。`id` は照合用の論理名、`domain` は扱う実物・業務の範囲、`target` は個別対象（null はその分野の各対象）、`scene` は発動条件、`action` は動作名、`text` は求める取り扱い、`excludes` は明示除外の配列。個別の対象だけで発動する規則もある。条件を満たした事実がない場合、条件付きの指示を有効とみなさない。実物を扱う規則は、実物を描いた紙や縮尺模型に当然には及ばない。`key_phrase` は語の重なりを採点するための注釈。
- 登録時は全行を有効な別々の規則として、ファイル順に一つの保存へ入れる。近い規則があっても他の条件を消したり、既存版を置き換えたりしない。元発言が必要なアダプターは `scene`・`text`・`target`・`excludes` から条件と例外を保った登録文を作る。空でない `domain` も適用範囲として伝える。実際の版IDと論理名の対応を評価器が保持する。IDや `key_phrase` を検索語・登録用別名に使わない。
- `queries.jsonl` の1行が1機会。装置に渡せるのは `input` だけ。場面文だけの照会に、評価器が動作・対象・翻訳・同義語を補ってはならない。構造化照会は `action` と `target` の2項目だけ。`must` は**該当する全規則**、`must_not` はとくに紛らわしい禁止規則の集合。`reason` と `level` は評価側でのみ使う。禁止リストの外の余分な規則も完全一致では誤りとする。
- `manifest.json` は件数・内訳・比較条件・データのハッシュを固定する。検査はリポジトリのルートで `python3 tests/discrimination/tools/validate.py`。このコマンドは静的検査だけを行う。

## 重なりの判定

[既存の S1 の定義](../scenes/README.md)と同じく、規則側は本文・場面・動作名を合わせ、NFKC＋小文字化した英数字の連続と、日本語の各文字をトークンにする。英語の語尾や日本語の助詞も勝手に除かない。照会側は自由文、構造化照会ではそのままの動作名・対象の順とする。分野・除外・採点注釈をトークン集合に加えない。これは**語彙の重なり**の診断であり、意味の難しさを保証する分類ではない。

1. 正解がある場合の比較対象は `must` の全規則。該当なしの場合だけ、比較する正解文が存在しないため `must_not` の近隣規則を用いる。
2. 比較対象のどれかの `key_phrase` が照会側に連続したトークン列として現れれば `shared`。中心語句は登録文・場面・動作のいずれかに実在するものだけを指定した。
3. 中心語句の完全な反復はないが比較対象のどれかと1トークン以上重なれば `partial`。すべての比較対象との共通トークンがゼロなら `zero`。複数正解のレベルは集合全体に対して一つ。正解なしの zero は、全72件のどの語とも重ならないという意味ではない。

## 測定方法

同じ保存の初期スナップショットを使い、全152問を、判定器あり・なしの各条件で一度ずつ実行する。毎回新しい読み手にし、結果の採用通知・例外追加・成功した語の辞書登録等を行わない。返却予算、初回の検索モード、候補上限、登録内容をそろえる。判定器ありの条件ではアダプター・モデル版・閾値を記録する。比較の途中で正解に合わせて調節しない。

初回の返答に有効な規則として実際に入った論理IDの集合を R、必須集合を G、禁止集合を F とする。続きを取得すれば見える記録、内部候補、元発言のIDは R に含めない。続きがある場合も初回だけで採点する。

| 指標 | 算出方法 |
|---|---|
| 必須規則の初回再現率 | 正解ありの機会で、Σ&#124;R∩G&#124; / Σ&#124;G&#124;。複数正解を一部しか拾えない場合に部分点を与える。 |
| 禁止規則の誤返却率 | F の規則を1件以上返した機会数 / 全機会数。併せて誤返却した禁止IDの延べ件数も報告する。 |
| 完全一致率 | R = G の機会数 / 全機会数。禁止に明記されていない別分野の規則を1件余分に返しても不合格。 |
| 該当なし正答率 | G が空の機会のうち、正常な初回返答で R が空だった数 / G が空の機会数。 |

**各指標を判定器の2条件 × 重なりの3段階の6セルで報告する。** 分子・分母と全体値も載せる。分母ゼロは未測定。失敗・未応答を正常0件に置き換えない。失敗時は再現と完全一致と該当なし正答の成功数に入れず、分母に残す。禁止の誤返却率は観測できた誤返却数なので、未応答件数を併記し、未応答をすべて誤返却とみなした上限も示す。判定器障害後に基本検索の有効な結果が返る場合は返答どおりに採点し、障害を別計数する。

このセットはデータと正解を固定するもの。装置・判定器の実測結果は収録していない。

## 独立確認用の第2セット

`holdout2.jsonl` は、同じ72規則に対する新規の80問。各行の形式、語の重なり、初回返答の4指標は既存セットと共通。手法・設定・予算を先に固定し、各条件で80問すべてを一度ずつ評価する。調整用の152問とは集計を分ける。閾値や判定器への説明をこの80問で調節した場合、その後の値は独立確認の成績として扱わない。manifest の従来の件数欄は既存152問用、`holdout2` 欄は今回の80問用。静的検査は両セット間のID・入力の重複も確認する。
