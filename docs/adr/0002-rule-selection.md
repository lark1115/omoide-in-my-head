# ADR-0002　規則を初回の検索結果に入れる条件

REQ-RECALL-1 (c)(d)(e)(f)(j) と REQ-JUDGE-1 に適用する。対象・除外・現行版の既存の絞り込みを先に行う。

場面文で規則を検索するとき、問い合わせの重複を除いた語の12%以上が規則の本文・場面・別表現に含まれることを求める。さらに、当たった語数に、対象や動作名に含まれない場面の語の当たり数を足す。この値が候補規則の最大値の60%以上なら残す。境界は両方とも含む。動作名に直接結びつく規則は従来通り残す。規則以外の記録と残った記録同士には従来の順位を使う。候補が残らない場合の応答は none。近いだけの規則を別枠で渡す機能は設けない。

判定器に渡す規則は、対象と動作の指定だけがあるとき、その動作に結びついたものに絞る。場面文のある照会には語の事前選別を適用しない。DEV で緩い語の条件でも必要規則を落としたため。対象に関係する事実など、ほかの種類の候補はこの動作条件の対象外。

jev-1.14.0 の設定例には閾値0.60を使う。ほかの判定器の既定値は各モデルの較正を前提にできないため0.50を保つ。問い合わせ・候補の送信項目と、各候補の確率を返す規約は従来どおり。語が違っても必要な複数規則を返せるよう、同じ対象・動作の最大確率からの差による足切りは採用しない。

比較は凍結した奇数IDの76問で行った。初回完全一致数を最大化し、必要規則の再現率が基準から10ポイントを超えて落ちる候補、既存の受入場面を悪化させる候補を除いた。語の条件の強化は単独で意味の適用を証明できない。数値はこの架空の規則集とモデル版に依存する。
